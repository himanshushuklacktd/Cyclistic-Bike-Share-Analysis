# Cyclistic Bike-Share Analysis

## Project Summary

Analyzed approximately 3.48 million Cyclistic bike-share rides from April 2020 to March 2021 to understand differences between casual riders and annual members.

## Tools Used

- Microsoft Excel
- Google BigQuery / SQL
- Tableau Public
- GitHub

## Key Findings

- Annual members generated more rides overall.
- Casual riders had significantly longer average ride durations.
- Casual rider activity was stronger on weekends.
- July and August showed high casual rider activity.
- Docked bikes had the highest overall usage.

## Business Recommendations

- Launch weekend-focused membership promotions.
- Target long-duration casual riders with membership offers.
- Increase marketing during July–August.
- Offer limited-time membership trials or discounts.
