# Methodology

## Project Period
April 2020 – March 2021

## Data Preparation
Monthly Cyclistic ride datasets were reviewed and cleaned using Microsoft Excel.

The cleaning process included:
- Removing invalid ride records
- Identifying negative and zero-duration rides
- Identifying unusually long rides
- Calculating ride length
- Calculating day of week
- Combining monthly datasets for analysis

## Data Analysis
The cleaned data was analyzed using Google BigQuery and SQL.

The analysis focused on:
- Total rides by user type
- Average ride duration
- Rides by day of week
- Monthly ride trends
- Bike type usage
- Average ride duration by bike type

## Data Visualization
The analysis results were visualized using Tableau Public.

The Tableau Story was created to communicate key differences between casual riders and annual members and to present business recommendations.

## Analytics Workflow

The project followed the Google Data Analytics framework:

1. Ask
2. Prepare
3. Process
4. Analyze
5. Share
6. Act
