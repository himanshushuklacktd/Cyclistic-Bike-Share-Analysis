# Raw Data

The original Cyclistic bike-share datasets cover the period:

**April 2020 – March 2021**

## Dataset Overview

- **Monthly datasets:** 12
- **Total rides:** Approximately 3.48 million
- **Combined data size:** Approximately 646 MB

The raw datasets are not included in this repository because of their large file size.

## Source

The dataset was obtained from the official Divvy/Cyclistic bike-share data source:

https://divvybikes.com/system-data

The data was used for educational and analytical purposes as part of the Google Data Analytics case study.
