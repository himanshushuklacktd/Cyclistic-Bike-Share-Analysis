# Data

The Cyclistic bike-share dataset used in this project covers the period:

**April 2020 – March 2021**

## Dataset Overview

- **Project period:** April 2020 – March 2021
- **Total rides:** Approximately 3.48 million
- **Combined dataset size:** Approximately 646 MB
- **Monthly datasets:** 12

The raw monthly datasets were used for data cleaning and analysis.

Due to the large file size of the dataset, the raw CSV files are not included in this GitHub repository.

The data was prepared and cleaned using Microsoft Excel before being analyzed using Google BigQuery and SQL.

The cleaned data was then visualized using Tableau Public.
